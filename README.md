# RAJASHEELA FOUNDATION Website (Reg No 552/26)

## Included Files
- `index.html` — Main sky blue & white website with top-left branding, Login modal trigger, About Us tile box, 12 Award Categories, Current Notification, Candidate Registration form, and Contact Us footer.
- `login.html` — Dedicated standalone Login page displaying the official circular Rajasheela Foundation (Reg No 552/26) logo.
- `style.css` — Custom CSS stylesheet for the sky blue & white color theme, glassmorphic navigation, circular logo frames, and scroll-triggered blur animations.
- `script.js` — Interactive JavaScript for scroll-blur reveal animations, login modal controls, form validation, and printable receipt slip generation.
- `logo.png` — Updated circular Rajasheela Foundation (Reg No 552/26) emblem cropped cleanly for circular frames.

## How to Use
1. Extract all files from the ZIP archive into a single folder.
2. Open `index.html` or `login.html` in any browser, or upload all 5 files together to your hosting provider.
