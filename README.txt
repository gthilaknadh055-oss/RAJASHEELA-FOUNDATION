RAJASHEELA FOUNDATION WEBSITE

The website uses a blue-and-white design and is mobile-friendly.
Files: index.html, style.css, script.js, Code.gs, application-form.pdf.

CONNECT GOOGLE SHEETS (PHONE-ONLY)
1. Create a Google Sheet.
2. Open Extensions > Apps Script (you may need Chrome > Desktop site).
3. Paste the contents of Code.gs into the Apps Script editor and save.
4. Deploy > New deployment > Web app.
5. Execute as: Me. Who has access: Anyone. Deploy and authorize.
6. Copy the Web App URL.
7. Open script.js and replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE with the URL.
8. Save and publish the website files using a static host such as GitHub Pages.

IMPORTANT: Until the Apps Script URL is configured, the form does not submit data.
Uploaded files are saved in a Google Drive folder; links are added to the spreadsheet.
The form requires exactly two passport-size photos. Max upload size is 8 MB per file.
Test with sample data and secure access to the spreadsheet and Drive folder before sharing publicly.
