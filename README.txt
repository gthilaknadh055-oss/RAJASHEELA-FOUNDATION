RAJASHEELA FOUNDATION WEBSITE

Files:
- index.html: website page
- style.css: layout, responsive styling and animations
- script.js: navigation, reveal animations and front-end form checks
- logo.png: Foundation logo

To preview: keep all files in the same folder and open index.html in a browser.

Candidate Registration now includes two optional PDF attachment fields. The current form is front-end only: it validates entries in the browser but does not upload applications or PDF attachments to a server. Connect a secure backend (for example, Google Apps Script) before accepting live submissions.

The payment area is placed immediately after Candidate Registration. Replace its placeholder with the Foundation's verified payment QR image before publishing. Do not use an unverified QR code.
