RAJASHEELA FOUNDATION WEBSITE

Files included:
- index.html: website page
- style.css: responsive styling and animations
- script.js: navigation, reveal animations and front-end form checks
- logo.png: Foundation logo
- sample-payment-qr.png: clearly labelled demo QR (not a real UPI/payment QR)

To preview: keep all files in the same folder and open index.html in a browser.

IMPORTANT: The ₹2,999 QR is a sample only. It encodes demo text and is not connected to a bank account or UPI ID. Replace it with the Foundation's verified UPI QR image before accepting payments.

Candidate Registration includes two optional PDF attachment fields. The current form is front-end only: it validates entries in the browser but does not upload applications or PDF attachments to a server. Connect a secure backend before accepting live submissions.
